This project is a real-time face recognition system (access control recognition). 
It uses Yolov8-Face for face detection, Dlib for 5-point key point detection to align the faces, and MobileFaceNet for face feature comparison.
This code can be directly run on the Raspberry Pi 5.

Attention: 
  1.the face_database has been deleted, you should obtain it by yourself.
  2.Except for the above, there are many other functions you can test with AI.
